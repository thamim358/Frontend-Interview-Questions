TOP 1
What is a closure? Give a real-world use case. ⭐
🟢 Beginner ⭐ Frequently Asked
Answer

A closure is a function that has access to variables from its outer scope even after the outer function has returned.

Example
PDF Guide — Closure + data privacy
function outerFunction(x) {
  return function innerFunction(y) {
    return x + y; // innerFunction has access to x
  };
}
const add5 = outerFunction(5);
console.log(add5(3)); // 8

// Practical example — data privacy
function createCounter() {
  let count = 0;
  return {
    increment: () => ++count,
    decrement: () => --count,
    getCount: () => count
  };
}
const counter = createCounter();
console.log(counter.getCount()); // 0
counter.increment();
console.log(counter.getCount()); // 1
Follow-up

1. Closures in loops with var vs let? 2. How do closures cause memory leaks? 3. Where have you used closures in React?

Common Mistake

Saying closure is "an inner function". The key is persistent access to outer scope after outer returned.

function deepCopy(obj) {
  if (obj === null || typeof obj !== 'object') return obj;
  if (obj instanceof Date) return new Date(obj);
  if (obj instanceof Array) return obj.map(item => deepCopy(item));

  return copied;

Event delegation + bubbling vs capturing. ⭐
🟢 Beginner ⭐ Frequently Asked
Answer

Event delegation uses event bubbling to handle events on parent elements instead of individual child elements. Event delegation is a technique where you attach a single event listener to a parent element, and that listener can handle events for current and future child elements using event bubbling. It bubbles up to the parent (and up the DOM tree). The parent's event listener can detect which child triggered the event using event.target.

Example
PDF Guide — Event delegation
// Instead of adding listeners to each button
document.querySelectorAll('button').forEach(button => {
  button.addEventListener('click', handleClick);
});

// Use event delegation on parent
document.getElementById('container').addEventListener('click', (e) => {
  if (e.target.tagName === 'BUTTON') {
    handleClick(e);
  }
});

// React example

    if (e.target.dataset.action) {
      console.log('Action:', e.target.dataset.action);
    }

    <div onClick={handleClick}>
      <button data-action="save">Save</button>
      <button data-action="cancel">Cancel</button>
      <button data-action="delete">Delete</button>

TOP 31
Implement Promise.all from scratch. 💻🔴
🔴 Advanced 💻 Coding
Answer

Wrap each entry with Promise.resolve, store results by index, count completions, resolve when all done, reject on first error. Handle empty array → resolve([]).

Example
promiseAll core
function promiseAll(items) {
  return new Promise((res, rej) => {
    const arr = [...items]; if (!arr.length) return res([]);
    const out = new Array(arr.length); let done = 0;

13. Advanced — Extra

AD1
Throttle implementation (leading + trailing). 💻🟡
🟡 Intermediate 💻 Coding
Answer

Track last-run time + pending timer. Leading fires immediately; trailing fires last args after window. Preserve this/args; expose cancel.

Throttle core
function throttle(fn, ms) {
  let last = 0, timer;
  return function (...a) {
    const now = Date.now(), rem = ms - (now - last);
    if (rem <= 0) { clearTimeout(timer); last = now; fn.apply(this, a); }
    else if (!timer) timer = setTimeout(() => { last = Date.now(); timer = null; fn.apply(this, a); }, rem);
  };
}

AD2
Custom minimal Promise (then/catch). 💻🔴
🔴 Advanced 💻 Coding
Answer

Store state + value, queue handlers, flush async via queueMicrotask. then returns new promise chaining through handlers with try/catch. Minimal version omits full thenable assimilation.

Tiny promise sketch

  constructor(ex) { this.st = 'p'; this.q = []; ex(v => this._ok(v), e => this._bad(e)); }
  _run() { queueMicrotask(() => this.q.splice(0).forEach(f => f())); }
  _ok(v) { if (this.st !== 'p') return; this.st = 'f'; this.v = v; this._run(); }
  _bad(e) { if (this.st !== 'p') return; this.st = 'r'; this.v = e; this._run(); }
  then(onF, onR) { return new Mini((res, rej) => this.q.push(() => {
    try { const f = this.st === 'f' ? onF : onR;
      if (!f) return (this.st === 'f' ? res : rej)(this.v);
      res(f(this.v)); } catch (e) { rej(e); } })); }
}

CD1
Event Emitter (on/off/emit/once). 💻🟡
🟡 Intermediate 💻 Coding
Answer

Map event → Set of listeners (Set auto-dedups + O(1) delete). emit copies listeners before invoking (safe if a listener unsubscribes mid-emit). once wraps and self-removes.

Emitter core
class Emitter {
  constructor() { this.m = new Map(); }
  on(e, fn) { if (!this.m.has(e)) this.m.set(e, new Set()); this.m.get(e).add(fn); }
  off(e, fn) { this.m.get(e)?.delete(fn); }
  emit(e, ...a) { [...(this.m.get(e) || [])].forEach(fn => fn(...a)); }
}

CD2
LRU Cache with Map (O(1)). 💻🔴
🔴 Advanced 💻 Coding
Answer

Map preserves insertion order. get: delete + re-set to mark recent. put: delete existing, set new, evict oldest (map.keys().next()) when over capacity.

LRU core
class LRU {
  constructor(cap) { this.cap = cap; this.m = new Map(); }
  get(k) { if (!this.m.has(k)) return -1; const v = this.m.get(k); this.m.delete(k); this.m.set(k, v); return v; }
  put(k, v) { if (this.m.has(k)) this.m.delete(k); this.m.set(k, v); if (this.m.size > this.cap) this.m.delete(this.m.keys().next().value); }
}
