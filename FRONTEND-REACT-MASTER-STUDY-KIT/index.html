📖 How to Use This Handbook

🎯 Start with P1

Master all P1 (Must Know) questions first — they cover 80% of interview scenarios. Then P2 for breadth. P3 for senior roles.

🔁 Progressive Learning

JavaScript → TypeScript → React Core → React Advanced → Next.js. Then branch to State Management, Testing, System Design.

📝 Practice Aloud

Read the Short Answer sections aloud. Then explain the concept in your own words. Prepare 5-7 STAR behavioral stories with data.

🖨 Print to PDF

Press Ctrl+P (Cmd+P on Mac) → Save as PDF. The CSS includes print optimization. Open HTML files in Chrome for best results.
