## How to Use

1. Open any `.html` file in your browser for the premium dark theme experience.
2. Press `Ctrl+P` → "Save as PDF" to create printable study guides.
3. Start with P1 (Must Know) questions — they cover 80% of interview scenarios.
4. Practice coding problems from memory before looking at solutions.
5. Use the Mock Interview Handbook to simulate real interview conditions.
