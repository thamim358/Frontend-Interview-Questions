01
Two Sum — Find two numbers that add to target
Beginner P1
Problem

Given an array of integers nums and an integer target, return indices of the two numbers that add up to target. Assume exactly one solution, and you may not use the same element twice.

Approach

Hash Map (Optimal): Single pass. For each number, compute its complement (target - num). If the complement exists in the hash map, we have our pair. Otherwise, store the current number and its index. This avoids the O(n²) nested loop approach.

Solution
JavaScript — Two Sum (O(n) Time, O(n) Space)
function twoSum(nums, target) {
  const map = new Map();

  for (let i = 0; i < nums.length; i++) {
    const complement = target - nums[i];

    if (map.has(complement)) {
      return [map.get(complement), i];
    }

    map.set(nums[i], i);
  }

  return [];  // Per problem constraints, will always find a solution
}
Complexity
MetricValueWhy
TimeO(n)Single pass through the array
SpaceO(n)Hash map stores up to n entries in worst case
Frontend Relevance

The hash map pattern appears everywhere: memoization caches, dependency tracking in React's hooks (the hooks linked list is essentially a positional map), deduplication, and event delegation lookups. This pattern is the foundation for Memoize (Problem 10).

02
Valid Parentheses — Check bracket matching
Beginner P1
Problem

Given a string containing just ( ) { } [ ], determine if the input string is valid — open brackets must be closed by the same type, in the correct order.

Approach

Stack: Push opening brackets onto a stack. For each closing bracket, pop the stack — the popped element must be the matching opening bracket. If the stack is empty at the end, the string is valid. This is the same algorithm a browser's HTML parser uses to match tags.

Solution
JavaScript — Valid Parentheses (O(n) Time, O(n) Space)
function isValid(s) {
  const stack = [];
  const pairs = {
    ')': '(',
    '}': '{',
    ']': '[',
  };

  for (const char of s) {
    if (char in pairs) {
      if (stack.pop() !== pairs[char]) return false;
    } else {
      stack.push(char);
    }
  }

  return stack.length === 0;
}
Frontend Relevance

This is literally how browsers parse HTML/JSX. When React reconciles the Virtual DOM, it uses stack-based diffing. The {'{'}...{'}'} nesting in JSX follows the same validation logic. Babel and ESLint parsers use stack-based bracket matching internally.

Interview Tip

If asked about HTML/JSX parsing, mention this algorithm. "A valid HTML document is just a valid parentheses problem with angle brackets." Interviewers love when you connect CS fundamentals to frontend.

03
Implement Debounce — with leading/trailing edge and cancel
Intermediate P1
Problem

Implement a debounce function that delays invoking fn until after delay milliseconds have elapsed since the last invocation. Support: (1) leading — invoke on the leading edge, (2) trailing — invoke on the trailing edge (default), (3) cancel — cancel pending invocations, (4) flush — immediately invoke any pending call.

Approach

Use setTimeout with a closure over a timerId. Each call clears the previous timer and sets a new one. For leading edge, invoke immediately and block subsequent calls for the delay period. For cancel, call clearTimeout. Return the debounced function with .cancel() and .flush() methods attached.

Solution
JavaScript — Production Debounce
function debounce(fn, delay, options = {}) {
  const { leading = false, trailing = true } = options;
  let timerId = null;
  let lastArgs = null;
  let lastThis = null;
  let lastCallTime = 0;

  function invoke() {
    fn.apply(lastThis, lastArgs);
    lastArgs = lastThis = null;
  }

  function debounced(...args) {
    lastArgs = args;
    lastThis = this;
    const now = Date.now();
    const elapsed = now - lastCallTime;

    if (timerId) clearTimeout(timerId);

    if (leading && elapsed >= delay) {
      invoke();
    } else if (trailing) {
      timerId = setTimeout(() => {
        invoke();
        timerId = null;
      }, delay);
    }

    lastCallTime = now;
  }

  debounced.cancel = () => {
    if (timerId) clearTimeout(timerId);
    timerId = lastArgs = lastThis = null;
  };

  debounced.flush = () => {
    if (timerId) { clearTimeout(timerId); invoke(); }
    timerId = null;
  };

  return debounced;
}
Complexity
MetricValue
Time per callO(1) — just clearing/setting a timeout
SpaceO(1) — constant state (timerId, lastArgs)
Frontend Relevance

Search inputs, window resize handlers, save-as-you-type (Think Medium, Google Docs). Leading-edge debounce is used for button clicks (prevent double-submit). Trailing-edge for search autocomplete. The cancel method is critical in React — you must cancel pending debounces on component unmount to avoid state updates on unmounted components.

04
Implement Throttle — Rate-limit function calls
Intermediate P1
Problem

Implement a throttle function that ensures fn is called at most once every delay milliseconds. If calls arrive during the cooldown period, schedule one trailing call.

Approach

Track lastCallTime. On each invocation, if enough time has elapsed since the last call, invoke immediately. Otherwise, schedule a trailing call with setTimeout for the remaining wait time. Ensure only one pending trailing call exists at a time.

Solution
JavaScript — Throttle with Trailing Edge
function throttle(fn, delay) {
  let lastCallTime = 0;
  let timerId = null;
  let lastArgs = null;
  let lastThis = null;

  return function throttled(...args) {
    lastArgs = args;
    lastThis = this;
    const now = Date.now();
    const elapsed = now - lastCallTime;

    if (elapsed >= delay) {
      fn.apply(lastThis, lastArgs);
      lastCallTime = now;
      lastArgs = lastThis = null;
    } else if (!timerId) {
      timerId = setTimeout(() => {
        fn.apply(lastThis, lastArgs);
        lastCallTime = Date.now();
        timerId = lastArgs = lastThis = null;
      }, delay - elapsed);
    }
  };
}
Frontend Relevance

Scroll event handlers (infinite scroll, parallax effects), window resize observers, game loops (requestAnimationFrame throttled at 60fps), tracking user mouse movement for heatmaps, and API rate limiting on the client side.

Memory Trick: Debounce = "wait until they stop" (search input). Throttle = "at most once every X ms" (scroll handler). Debounce resets the timer; throttle enforces a cooldown.
05
Implement Promise.all — Parallel execution with order preservation
Intermediate P1
Problem

Implement Promise.myAll(promises) that takes an iterable of promises and returns a single promise that resolves to an array of results (in input order) or rejects with the first rejection.

Approach

Track resolved count and use the index to place results in the correct position (not push order — promises may resolve in any order). Reject immediately on first error. Handle the empty array edge case (resolve immediately with empty array). Accept both promises and plain values (wrap non-promises with Promise.resolve).

Solution
JavaScript — Promise.myAll
Promise.myAll = function (promises) {
  const items = Array.from(promises);
  const total = items.length;

  return new Promise((resolve, reject) => {
    if (total === 0) return resolve([]);

    const results = new Array(total);
    let resolved = 0;

    items.forEach((item, index) => {
      Promise.resolve(item)
        .then(value => {
          results[index] = value;
          resolved++;

          if (resolved === total) resolve(results);
        })
        .catch(reject);
    });
  });
};
Critical Details
DetailWhy It Matters
Use results[index] not pushPreserves input order regardless of resolution order
Wrap with Promise.resolve(item)Accepts plain values (not just promises)
Empty array → resolve immediatelyMatches native Promise.all([]) behavior
Reject on first errorFail-fast behavior — matches the spec
Frontend Relevance

Parallel API calls on page load (fetch user profile + settings + notifications simultaneously). React's Suspense with multiple data sources. Promise.allSettled variant shows all results (successes + failures) — useful for dashboards where one failing widget shouldn't break the entire page.

06
Deep Clone Object — Handle circular refs, Date, Map, Set
Advanced P1
Problem

Implement a deep clone function that creates a complete independent copy of any JavaScript value. Must handle: objects, arrays, Date, RegExp, Map, Set, nested structures, and circular references. Do not use structuredClone or JSON.parse(JSON.stringify()).

Approach

Use a WeakMap to track visited objects (handles circular refs). For each value type: primitives return directly, Date/RegExp construct new instances, Map/Set iterate entries recursively, arrays and plain objects create new containers and recurse. The WeakMap ensures each source object maps to exactly one clone — breaking circular chains.

Solution
JavaScript — Deep Clone with Circular Reference Handling
function deepClone(value, cache = new WeakMap()) {
  // Primitives and functions (return as-is; functions are shared, not cloned)
  if (value === null || typeof value !== 'object') return value;

  // Circular reference: return cached clone
  if (cache.has(value)) return cache.get(value);

  // Date
  if (value instanceof Date) {
    const clone = new Date(value.getTime());
    cache.set(value, clone);
    return clone;
  }

  // RegExp
  if (value instanceof RegExp) {
    const clone = new RegExp(value.source, value.flags);
    cache.set(value, clone);
    return clone;
  }

  // Map
  if (value instanceof Map) {
    const clone = new Map();
    cache.set(value, clone);
    value.forEach((v, k) => clone.set(deepClone(k, cache), deepClone(v, cache)));
    return clone;
  }

  // Set
  if (value instanceof Set) {
    const clone = new Set();
    cache.set(value, clone);
    value.forEach(v => clone.add(deepClone(v, cache)));
    return clone;
  }

  // Array
  if (Array.isArray(value)) {
    const clone = [];
    cache.set(value, clone);
    value.forEach((item, i) => { clone[i] = deepClone(item, cache); });
    return clone;
  }

  // Plain Object
  const clone = {};
  cache.set(value, clone);
  for (const key of Object.keys(value)) {
    clone[key] = deepClone(value[key], cache);
  }
  return clone;
}
Frontend Relevance

Immutable state updates in Redux (you must clone before mutating), creating snapshots for undo/redo, form draft saving, and copying complex state trees without shared references. The cache WeakMap is also how structuredClone handles circular refs internally.

Senior Insight

Use structuredClone(value) in production (Node 17+, all modern browsers). But you must be able to implement it from scratch — this question tests recursion, type checking, and circular reference handling in one problem.

07
Implement Array.map Polyfill — with thisArg and sparse arrays
Intermediate P1
Problem

Implement Array.prototype.myMap that behaves exactly like the native Array.prototype.map — including correct this binding, skipping holes in sparse arrays, and passing the correct arguments (element, index, array) to the callback.

Solution
JavaScript — Array.map Polyfill
Array.prototype.myMap = function (callback, thisArg) {
  if (typeof callback !== 'function') {
    throw new TypeError('callback must be a function');
  }

  const length = this.length;
  const result = new Array(length);

  for (let i = 0; i < length; i++) {
    // Skip holes in sparse arrays (hasOwnProperty check)
    if (i in this) {
      result[i] = callback.call(thisArg, this[i], i, this);
    }
    // Holes remain as empty slots (not undefined)
  }

  return result;
};
Critical Details

(1) i in this checks for holes in sparse arrays (e.g., new Array(5) has length 5 but no indices). The native .map skips these. (2) callback.call(thisArg, ...) passes the correct this context. (3) The result array is pre-allocated with new Array(length) to preserve sparse slots.

Frontend Relevance

Understanding .map's internals helps you avoid the common bug of using it where .forEach is needed (when you don't need the returned array). The thisArg parameter is often forgotten — but React class components originally relied on .map(this.renderItem, this) pattern.

08
Implement Function.bind Polyfill — Partial application + new keyword
Advanced P1
Problem

Implement Function.prototype.myBind that returns a new function with a bound this and optionally preset arguments. The bound function must work correctly when called with the new keyword (in which case, the bound this is ignored and the newly created object is used).

Solution
JavaScript — Function.bind Polyfill
Function.prototype.myBind = function (context, ...boundArgs) {
  const originalFn = this;

  if (typeof originalFn !== 'function') {
    throw new TypeError('Function.prototype.bind called on non-function');
  }

  function boundFn(...callArgs) {
    // If called with 'new', `this` is the newly created instance
    // Use instanceof to detect 'new' calls
    const isNewCall = this instanceof boundFn;
    const finalContext = isNewCall ? this : context;

    return originalFn.apply(finalContext, [...boundArgs, ...callArgs]);
  }

  // Preserve prototype chain for instanceof checks
  if (originalFn.prototype) {
    boundFn.prototype = Object.create(originalFn.prototype);
  }

  return boundFn;
};
Critical Details

The new keyword handling is the trickiest part. When new boundFn() is called, the engine creates a new object whose __proto__ points to boundFn.prototype. Inside the call, this instanceof boundFn is true — we must use this (the new instance) instead of the bound context. We also preserve the original prototype so new boundFn() instanceof originalClass works.

Frontend Relevance

React class components used .bind(this) extensively before hooks. Even today, event handlers sometimes need bound this (e.g., when passing callbacks to third-party libraries that call them with a different context). Understanding bind is essential for debounce/throttle implementations that need to preserve this.

09
Flatten Nested Array — Recursive + iterative with depth
Intermediate P1
Problem

Implement Array.prototype.myFlat(depth = 1) that flattens a nested array up to the specified depth. depth = Infinity should flatten completely.

Solution
JavaScript — Flatten (Recursive + Iterative)
// Recursive — cleaner, intuitive
Array.prototype.myFlatRecursive = function (depth = 1) {
  const result = [];

  for (const item of this) {
    if (Array.isArray(item) && depth > 0) {
      result.push(...item.myFlatRecursive(depth - 1));
    } else {
      result.push(item);
    }
  }

  return result;
};

// Iterative (stack-based) — no recursion limit, handles Infinity depth
Array.prototype.myFlatIterative = function (depth = 1) {
  const stack = [...this];
  const result = [];

  while (stack.length) {
    const item = stack.shift();

    if (Array.isArray(item) && depth > 0) {
      stack.unshift(...item);  // Implicitly we need depth tracking
    } else {
      result.push(item);
    }
  }

  // Better iterative: push items with their depth
  // Stack entries: [item, currentDepth]
};
JavaScript — Depth-Aware Iterative Flatten
Array.prototype.myFlat = function (depth = 1) {
  const result = [];
  // Stack stores [arraySlice, remainingDepth]
  const stack = [[this, depth]];

  while (stack.length) {
    const [arr, currentDepth] = stack.pop();

    for (const item of arr) {
      if (Array.isArray(item) && currentDepth > 0) {
        stack.push([item, currentDepth - 1]);
      } else {
        result.push(item);
      }
    }
  }

  return result;
};
Frontend Relevance

Flattening nested menu structures (sidebar nav), processing hierarchical component trees (recursively extracting all leaf components), and normalizing deeply nested API responses into flat lists for virtualized rendering. React's React.Children.toArray effectively flattens nested children.

10
Implement Memoize — Cache with Map, JSON keys, and TTL
Advanced P1
Problem

Implement a general-purpose memoize(fn, options?) that caches function results based on arguments. Support: (1) custom key resolver (default: JSON.stringify), (2) Map-based cache with LRU eviction, (3) optional TTL (time-to-live) for entries.

Solution
JavaScript — Memoize with TTL and Resolver
function memoize(fn, options = {}) {
  const {
    resolver = (...args) => JSON.stringify(args),
    ttl = Infinity,        // Time-to-live in ms (default: no expiry)
    maxSize = Infinity,     // Max cache entries (default: unlimited)
  } = options;

  const cache = new Map();

  function memoized(...args) {
    const key = resolver(...args);
    const entry = cache.get(key);

    // Cache hit + not expired
    if (entry && (ttl === Infinity || Date.now() - entry.timestamp < ttl)) {
      return entry.value;
    }

    // Cache miss or expired — compute and store
    const value = fn.apply(this, args);

    // LRU eviction: if at capacity, delete oldest entry
    if (cache.size >= maxSize) {
      const oldestKey = cache.keys().next().value;
      cache.delete(oldestKey);
    }

    cache.set(key, { value, timestamp: Date.now() });
    return value;
  }

  // Utility methods
  memoized.cache = cache;
  memoized.clear = () => cache.clear();

  return memoized;
}
Frontend Relevance

This is exactly how React.useMemo and React.useCallback work conceptually (though React uses a simple dependency array comparison, not a full cache). Libraries like reselect for Redux use memoization to avoid recomputing derived data. React.memo memoizes component renders. The TTL pattern is used in React Query's staleTime and cacheTime.

11
Event Emitter / Pub-Sub — subscribe, emit, unsubscribe
Intermediate P2
Problem

Implement a pub-sub EventEmitter class with on(event, callback) (subscribe), emit(event, ...args) (publish), off(event, callback) (unsubscribe), and once(event, callback) (subscribe for one invocation).

Solution
JavaScript — Event Emitter
class EventEmitter {
  constructor() {
    this._events = new Map();
  }

  on(event, callback) {
    if (!this._events.has(event)) {
      this._events.set(event, new Set());
    }
    this._events.get(event).add(callback);
    return this;  // Chaining support
  }

  off(event, callback) {
    if (this._events.has(event)) {
      this._events.get(event).delete(callback);
    }
    return this;
  }

  emit(event, ...args) {
    if (this._events.has(event)) {
      this._events.get(event).forEach(cb => cb(...args));
    }
    return this;
  }

  once(event, callback) {
    const wrapper = (...args) => {
      callback(...args);
      this.off(event, wrapper);
    };
    return this.on(event, wrapper);
  }
}
Frontend Relevance

Node.js EventEmitter, browser addEventListener/removeEventListener, React's synthetic event system, Redux middleware, WebSocket message routing, and custom event buses for cross-component communication in micro-frontend architectures. This is the Observer pattern — one of the Gang of Four patterns every senior frontend engineer should know.

Solution
JavaScript — Promise.race + timeout utility
Promise.myRace = function (promises) {
  const items = Array.from(promises);

  return new Promise((resolve, reject) => {
    for (const item of items) {
      Promise.resolve(item).then(resolve, reject);

// Common frontend use: API call with timeout
function fetchWithTimeout(url, options = {}, timeoutMs = 5000) {
  const fetchPromise = fetch(url, options);
  const timeoutPromise = new Promise((_, reject) =>
    setTimeout(() => reject(new Error(`Request timed out after ${timeoutMs}ms`)), timeoutMs)

13
Deep Equality Check — Used in React.memo comparison
Advanced P2
Solution
JavaScript — Deep Equality
function deepEqual(a, b) {
  // Same reference or both NaN
  if (a === b) return true;

  // Null/undefined check + type mismatch
  if (a == null || b == null) return a === b;
  if (typeof a !== typeof b) return false;
  if (typeof a !== 'object') return a === b;

  // Date
  if (a instanceof Date && b instanceof Date) {
    return a.getTime() === b.getTime();
  }

  // RegExp
  if (a instanceof RegExp && b instanceof RegExp) {
    return a.source === b.source && a.flags === b.flags;
  }

  // Arrays
  if (Array.isArray(a) && Array.isArray(b)) {
    if (a.length !== b.length) return false;
    return a.every((item, i) => deepEqual(item, b[i]));
  }

  // Objects
  const keysA = Object.keys(a);
  const keysB = Object.keys(b);
  if (keysA.length !== keysB.length) return false;

  return keysA.every(key =>
    Object.prototype.hasOwnProperty.call(b, key) && deepEqual(a[key], b[key])
  );
}
Frontend Relevance

React.memo uses shallow equality by default — you can provide a custom areEqual function using this logic. Jest's .toEqual() uses a similar deep equality algorithm. Redux selectors use shallow or deep equality to determine if state has changed.

14
LRU Cache — O(1) get/put with capacity
Advanced P2
Solution — Using JavaScript Map's Insertion Order
JavaScript — LRU Cache (Map-based, O(1))
class LRUCache {
  constructor(capacity) {
    this.capacity = capacity;
    this.map = new Map();
  }

  get(key) {
    if (!this.map.has(key)) return -1;
    // Move to end (most recently used) by delete + re-set
    const value = this.map.get(key);
    this.map.delete(key);
    this.map.set(key, value);
    return value;
  }

  put(key, value) {
    // If key exists, delete first (will re-insert as fresh)
    if (this.map.has(key)) this.map.delete(key);
    // Evict oldest: JS Map's .keys().next() is first-inserted key
    else if (this.map.size === this.capacity) {
      const lruKey = this.map.keys().next().value;
      this.map.delete(lruKey);
    }
    this.map.set(key, value);
  }
}
Frontend Relevance

Browser HTTP cache, React Query's garbage collection, image lazy-loading caches, virtual list rendered item caches, and service worker caching strategies. The Map trick is JavaScript-specific — leverages the fact that Map.keys() preserves insertion order, making LRU O(1) without a doubly-linked list.

Beginner P3
Solution
JavaScript — Valid Palindrome O(n)
function isPalindrome(s) {
  s = s.toLowerCase().replace(/[^a-z0-9]/g, '');
  let left = 0, right = s.length - 1;

  while (left < right) {
    if (s[left] !== s[right]) return false;
    left++; right--;
  }
  return true;
}

Maximum Subarray — Kadane's Algorithm
Intermediate P3
Solution
JavaScript — Kadane's Algorithm O(n)
function maxSubArray(nums) {
  let maxEndingHere = nums[0];
  let maxSoFar = nums[0];

  for (let i = 1; i < nums.length; i++) {
    maxEndingHere = Math.max(nums[i], maxEndingHere + nums[i]);
    maxSoFar = Math.max(maxSoFar, maxEndingHere);
  }

  return maxSoFar;
}
Frontend Relevance

The "running maximum/sum" pattern applies to: measuring cumulative layout shift (CLS) scores, tracking the largest frame in Performance Observer, calculating maximum concurrent WebSocket connections for capacity planning, and computing sliding window aggregates in data visualization dashboards.

Implement Array.reduce Polyfill — Initial value handling
Intermediate P2
Solution
JavaScript — Array.reduce Polyfill
Array.prototype.myReduce = function (callback, initialValue) {
  if (typeof callback !== 'function') {
    throw new TypeError('callback must be a function');
  }

  const length = this.length;
  let i = 0;
  let accumulator;

  // If no initialValue, use first element (skip holes)
  if (arguments.length < 2) {
    while (i < length && !(i in this)) i++;
    if (i >= length) throw new TypeError('Reduce of empty array with no initial value');
    accumulator = this[i++];
  } else {
    accumulator = initialValue;
    // Skip holes to find first iteration starting point
  }

  for (; i < length; i++) {
    if (i in this) {
      accumulator = callback.call(undefined, accumulator, this[i], i, this);
    }
  }

  return accumulator;
};
Frontend Relevance

Pipeline/chain patterns (compose, pipe), Redux reducers are reduce over actions, computing aggregate values from data (total cart price, grouped-by-category), and transforming state trees functionally. Understanding reduce deeply unlocks functional programming patterns.

Currying — sum(1)(2)(3) and infinite currying
Intermediate P2
Solution
JavaScript — sum(1)(2)(3) and infinite sum(...)(...)
// Fixed arity: sum(1)(2)(3) → 6
function sum(a) {
  return function (b) {
    return function (c) {
      return a + b + c;
    };
  };
}

// Generic curry: converts f(a,b,c) into f(a)(b)(c)
function curry(fn) {
  return function curried(...args) {
    if (args.length >= fn.length) {
      return fn.apply(this, args);
    }
    return (...nextArgs) => curried(...args, ...nextArgs);
  };
}

// Infinite currying: sum(1)(2)(3)() or implicit toString/valueOf
function infiniteSum(a) {
  const fn = (b) => infiniteSum(a + b);
  fn.valueOf = fn.toString = () => a;
  return fn;
}
// infiniteSum(1)(2)(3) == 6  // true (coerced via valueOf)
// +infiniteSum(1)(2)(3)       // 6 (explicit coercion)
Frontend Relevance

Redux middleware chain (store => next => action => {}) is curried. React's connect(mapState, mapDispatch)(Component) is curried. Event handler factories: handleClick(id)(event). CSS-in-JS tagged template literals are partial application. Currying enables function composition — a core functional programming concept that makes React code more testable and composable.

19
Longest Substring Without Repeating Characters — Sliding Window
Intermediate P3
Problem

Given a string, find the length of the longest substring without repeating characters. Input: "abcabcbb" → Output: 3 ("abc"). Input: "bbbbb" → Output: 1 ("b").

Solution
JavaScript — Sliding Window (O(n) Time, O(min(m,n)) Space)
function lengthOfLongestSubstring(s) {
  let maxLen = 0, start = 0;
  const charMap = new Map();

  for (let end = 0; end < s.length; end++) {
    const char = s[end];
    if (charMap.has(char)) {
      start = Math.max(start, charMap.get(char) + 1);
    }
    charMap.set(char, end);
    maxLen = Math.max(maxLen, end - start + 1);
  }
  return maxLen;
}
Frontend Relevance

Sliding window pattern for form input validation, real-time search parsing, and dynamic text pattern matching in rich text editors. Essential for understanding the classic "window" optimization — shrink when constraint is violated, expand when it's satisfied.

Valid Anagram — Frequency Counter Pattern
Beginner P3
Problem

Given two strings, determine if they are anagrams (contain the same characters in the same frequency). Input: "anagram", "nagaram" → true. Input: "rat", "car" → false.

Solution
JavaScript — Frequency Counter (O(n) Time, O(1) Space)
function isAnagram(s, t) {
  if (s.length !== t.length) return false;
  const count = {};
  for (const char of s) count[char] = (count[char] || 0) + 1;
  for (const char of t) {
    if (!count[char]) return false;
    count[char]--;
  }
  return true;
}
Frontend Relevance

Hash map frequency counting is fundamental for comparing data sets in React state, verifying filter/search results, and analyzing user input patterns. The pattern scales to any "does set A equal set B" problem.

Product of Array Except Self — Prefix/Suffix Pattern
Intermediate P3
Problem

Return an array where each element is the product of all other elements in the original array (without using division). Input: [1,2,3,4] → Output: [24,12,8,6].

Solution
JavaScript — Prefix/Suffix (O(n) Time, O(1) Extra Space)
function productExceptSelf(nums) {
  const result = new Array(nums.length).fill(1);
  let left = 1;
  for (let i = 0; i < nums.length; i++) {
    result[i] = left; left *= nums[i];
  }
  let right = 1;
  for (let i = nums.length - 1; i >= 0; i--) {
    result[i] *= right; right *= nums[i];
  }
  return result;
}
Frontend Relevance

Prefix/suffix pattern is crucial for computing accumulated values in tables, running totals in financial dashboards, and pre-computing derived data for React performance. The "two-pass" technique solves many array problems that seem to need O(n²).

Reverse a Linked List — Pointer Manipulation
Beginner P3
Problem

Reverse a singly linked list. Input: 1 → 2 → 3 → 4 → 5 → null → Output: 5 → 4 → 3 → 2 → 1 → null.

Solution
JavaScript — Iterative (O(n) Time, O(1) Space)
function reverseList(head) {
  let prev = null, curr = head;
  while (curr) {
    const next = curr.next;
    curr.next = prev;
    prev = curr;
    curr = next;
  }
  return prev;
}

Min Stack — Auxiliary Data Structure
Intermediate P3
Problem

Design a stack that supports push, pop, top, and retrieving the minimum element in O(1) time. MinStack() → push(-2), push(0), push(-3), getMin() → -3, pop(), top() → 0, getMin() → -2.

Solution
JavaScript — Min Stack with Auxiliary Stack (O(1) All Operations)
class MinStack {
  constructor() {
    this.stack = [];
    this.minStack = [];
  }
  push(val) {
    this.stack.push(val);
    if (!this.minStack.length || val <= this.minStack[this.minStack.length - 1]) {
      this.minStack.push(val);
    }
  }
  pop() {
    const val = this.stack.pop();
    if (val === this.minStack[this.minStack.length - 1]) {
      this.minStack.pop();
    }
  }
  top() { return this.stack[this.stack.length - 1]; }
  getMin() { return this.minStack[this.minStack.length - 1]; }
}
Frontend Relevance

Auxiliary data structure pattern: "track the min alongside the main data." Useful for monitoring React state values, tracking min/max in analytics dashboards, and managing undo/redo history with memory-efficient state snapshots. The "two stacks" pattern appears in many form state management libraries.

Implement Promise.allSettled — Wait for All, Handle All Outcomes
Intermediate P3
Problem

Implement Promise.allSettled — resolves after all promises settle (resolve or reject), returning an array of { status: "fulfilled", value } or { status: "rejected", reason } objects.

Solution
JavaScript — Promise.allSettled (O(n) Time)
function promiseAllSettled(promises) {
  return new Promise(resolve => {
    const results = [], items = Array.from(promises);
    if (!items.length) return resolve([]);
    let done = 0;
    const onSettle = (i, status, val) => {
      results[i] = { status, [status === 'fulfilled' ? 'value' : 'reason']: val };
      if (++done === items.length) resolve(results);
    };
    items.forEach((p, i) =>
      Promise.resolve(p).then(v => onSettle(i, 'fulfilled', v), r => onSettle(i, 'rejected', r))
    );
  });
}
Frontend Relevance

Fire multiple API requests and handle both successes and failures individually — loading independent dashboard widgets where one failure shouldn't block others. Unlike Promise.all (fail-fast), allSettled guarantees every promise completes before resolving.

Remove Duplicates from Sorted Array — Two Pointers (In-Place)
Beginner P3
Problem

Remove duplicates in-place from a sorted array and return the new length. Input: [0,0,1,1,1,2,2,3,3,4] → Output: 5, nums = [0,1,2,3,4,...].

Solution
JavaScript — Two Pointers (O(n) Time, O(1) Space)
function removeDuplicates(nums) {
  if (!nums.length) return 0;
  let i = 0;
  for (let j = 1; j < nums.length; j++) {
    if (nums[j] !== nums[i]) {
      i++; nums[i] = nums[j];
    }
  }
  return i + 1;
}
Frontend Relevance

In-place array manipulation with two-pointer technique. Directly applicable to deduplicating API response data, cleaning up user-submitted lists, and optimizing data before rendering in React components. The "slow/fast pointer" pattern appears in many array problems.

Contains Duplicate — Hash Set Lookup
Beginner P3
Problem

Given an array, return true if any value appears at least twice. Input: [1,2,3,1] → true. Input: [1,2,3,4] → false.

Solution
JavaScript — Hash Set (O(n) Time, O(n) Space)
function containsDuplicate(nums) {
  const seen = new Set();
  for (const n of nums) {
    if (seen.has(n)) return true;
    seen.add(n);
  }
  return false;
}
Frontend Relevance

Hash set is the simplest "have I seen this before" tool. Directly applicable to checking for duplicate React keys, ensuring unique items in sorted/filtered views, and validating unique constraints in form submissions.
